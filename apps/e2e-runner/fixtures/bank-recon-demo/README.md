# Synthetic bank reconciliation fixtures

Imported from BookOne at the revision in migration/source-inventory.json. Files model sample book entries, bank matches, an uncleared cheque and a bank fee. They are test examples, not real statements.

Use the root QA README for commands. Legacy account-specific demo/audit scripts are not active in this extraction. generate-xlsx.mjs regenerates an XLSX fixture locally; generated artifacts stay ignored until reviewed.
